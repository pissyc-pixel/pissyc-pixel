# Agent 知乎

**观点图谱与多 Agent 圆桌**

一个面向议题理解的产品 Demo。我负责产品方案、交互原型、Prompt 与角色设计，参与后端实现和联调。项目获 **知乎全球 A2A 黑客松知乎特别奖**。

## 从两类问题出发

已有充分讨论的问题，观点和依据往往分散在多个回答中，读者需要反复比较。新问题则可能缺少讨论，尚未呈现足够多的视角。

因此，我设计了两条交互路径：把已有回答组织成观点图谱，或通过多 Agent 圆桌补充讨论视角。

## 观点图谱

从回答中抽取观点、立场与依据，合并相近观点，将支持、反驳和补充关系呈现为图谱连接。产品重点是让用户比较共识与分歧，同时保留观点对应的依据。

## 多 Agent 圆桌

配置约 **20 个角色 Agent**，以角色文件约束身份边界，以 System Prompt 明确立场，再用动态 Prompt 指定当轮任务和回应对象。通过发言与回应调度，让角色围绕当前议题展开讨论。

围绕重复表达、讨论偏题和角色风格偏移，迭代角色约束与讨论规则。单次圆桌讨论最多 **5 轮**，切换辩题时新建会话，隔离不同议题的历史内容。

## 我的工作

- **产品方案与原型**：定义两类场景，设计从问题输入到图谱展示、圆桌讨论的交互流程。
- **Prompt 与角色设计**：整理角色立场、当轮任务、回应对象及讨论约束。
- **实现与联调**：参与后端实现，联调观点图谱展示与圆桌交互，完成可演示流程。
- **样例验证**：以小规模样例和人工抽查检查观点覆盖、依据可追溯、角色一致性与讨论推进，并据此调整 Prompt。

## 验证关注什么

图谱是否覆盖主要立场，能否找到对应依据；圆桌是否补充了不同视角，是否反复表达相同观点；角色能否保持一致，讨论是否持续围绕议题推进。

目前已完成 Demo 和多 Agent 联调，通过样例和人工检查持续调整产品流程与讨论规则。
